MANUEL UTILISATEUR OFFICIEL — INJS 2026
=======================================

Institut National de la Jeunesse et des Sports d'Abidjan
Version documentaire 1.0 — Édition 2026


PAR OÙ COMMENCER
----------------

  telechargements/index.html   Ouvre l'espace de téléchargement : PDF, archives,
                               rapport. C'est le point d'entrée conseillé.

  html/index.html              Le manuel interactif : recherche, filtres par
                               profil et par module, mode clair/sombre,
                               impression. Fonctionne hors ligne.

  pdf/MANUEL_UTILISATEUR_OFFICIEL_INJS_2026.pdf
                               Le manuel complet, 103 pages, prêt à imprimer
                               (ouvrir avec Acrobat, Aperçu, Edge, Firefox...).

  RAPPORT_PRODUCTION.md        Méthode, sources, vérifications et limites.

RÉGÉNÉRER LE MANUEL
-------------------

Depuis sources/contenu/ :

    python generer_pdf.py     produit pdf/MANUEL_UTILISATEUR_OFFICIEL_INJS_2026.pdf
    python generer_html.py    produit html/index.html

Prérequis : Python 3.11, reportlab, Pillow, et les polices DejaVu.
La génération PDF effectue plusieurs passes pour stabiliser la pagination du
sommaire : c'est normal, le nombre de passes est affiché.


À SAVOIR
--------

  - Aucune connexion internet n'est nécessaire : le manuel n'appelle aucune
    ressource externe.
  - Les captures proviennent toutes de l'application réelle. Aucune image n'a
    été fabriquée.
  - Deux profils (FORMATEUR et AUDITEUR) n'ont pas d'accès à l'interface web.
    Ils figurent dans le manuel pour une raison de traçabilité, et le document
    l'indique explicitement.
  - Aucune donnée personnelle, aucun identifiant ni secret ne figure dans ces
    fichiers.

Document institutionnel — diffusion interne.
