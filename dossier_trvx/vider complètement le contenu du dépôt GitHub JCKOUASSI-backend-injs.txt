Oui. Si ton objectif est de vider complètement le contenu du dépôt GitHub JCKOUASSI/backend-injs tout en conservant le dépôt lui-même et son historique Git, le plus sûr est de le faire depuis un clone temporaire propre, afin de ne toucher à aucun de tes travaux locaux actuels.

⚠️ Cela supprimera les fichiers de main sur GitHub après le commit/push. L’historique Git restera conservé.

Commandes groupées à exécuter dans le terminal VSCode

set -e
echo "=== CLONAGE PROPRE DU DEPOT ==="
cd ~/Desktop
rm -rf backend-injs-wipe
git clone https://github.com/JCKOUASSI/backend-injs.git backend-injs-wipe
cd backend-injs-wipe
echo "=== DEPOT / BRANCHE ==="
git remote -v
git branch --show-current
git status -sb
echo "=== CONTENU AVANT SUPPRESSION ==="
find . -mindepth 1 -maxdepth 1 ! -name .git -print
echo "=== SUPPRESSION DE TOUT LE CONTENU ==="
find . -mindepth 1 -maxdepth 1 ! -name .git -exec rm -rf -- {} +
echo "=== VERIFICATION ==="
find . -mindepth 1 -maxdepth 1 ! -name .git -print
echo "=== GIT STATUS ==="
git status --short
echo "=== AJOUT DES SUPPRESSIONS ==="
git add -A
echo "=== DIFF A COMMITTER ==="
git diff --cached --stat
git diff --cached --name-status
echo "=== COMMIT ==="
git commit -m "chore: purge repository contents"
echo "=== PUSH VERS GITHUB ==="
git push origin main
echo "=== VERIFICATION REMOTE ==="
git fetch origin
git status -sb
git log -1 --oneline --decorate origin/main
echo "=== TERMINE ==="
